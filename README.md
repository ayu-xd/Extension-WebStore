# DMDroid — Instagram DM Follow-up Assistant

Chrome extension that schedules and sends first messages and follow-ups
from your own logged-in Instagram account, with reply detection and
working-hours safety rails. Manage everything from the DMDroid dashboard.

## Install (developer mode)

1. Download and extract this package (keep the folder that contains manifest.json)
2. Open chrome://extensions
3. Enable Developer mode (top-right)
4. Click "Load unpacked" and select the extracted folder
5. Pin DMDroid to your toolbar, open the popup, and log in

Pairing with your dashboard is automatic after login.
